## Setup

- **Model:** `ollama/gpt-oss:20b` on the local GPU, `num_ctx = 16384`.
- **Router:** `offline = true`, with a remote candidate (`remote/big-model`, `https://remote.invalid/v1`) listed
  first in the `code` and `fast` classes. REQ-LLM-004 must discard it without contacting it.
- **Each run:**
  - a fresh copy of `e2e/us003/fixture` under git;
  - `go test ./...` typed in a new pane, failing;
  - an `auto-edit` thread in the copy, sent `fix it` with that block attached;
  - `run_command` approved once when the line is a single `go test`, anything else asked about denied;
  - the verdict from running `go test -count=1 ./...` again outside the daemon.
- **Success:** `go test ./...` green, `stats_test.go` unchanged, and git reporting no path changed but
  `stats.go`. A run that edits the test, adds a file or touches `go.mod` fails.
- **Offline:** the panes and the agent run with `GOTOOLCHAIN=local`, `GOPROXY=off` and `GOFLAGS=-mod=mod`.
- **Environment:** the daemon has its own XDG directories and `HOME`; the Go build and module caches are
  the developer's, which keeps a run's builds warm. Ollama keeps the model loaded (`keep_alive = "30m"`).
- **Measures:** "left after repair" counts the turns REQ-AGT-006 ended `tool_error` on an invalid
  retry — one unrepaired call each — over every tool call, which is how PRD §4.1 reads "the rate of invalid
  tool calls after repair". "Repairs that failed" puts the same count over the invalid calls. An invalid
  call whose turn ended for another reason before its retry is not counted. One model is measured.
