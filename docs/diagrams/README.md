# Diagrams

> Version 1.1 (2026-09-20): includes the `workspaces`, `waits`, `integrations` and `notify` modules and the phase boxes updated to specs 1.1.

| File | What it is |
|---|---|
| `umbral-architecture.excalidraw` | Editable source of the architecture infographic. Open it at <https://excalidraw.com> (menu → Open) or with the Excalidraw extension for VS Code. |
| `umbral-architecture.svg` | Hand-drawn render (roughjs) with the Virgil font embedded. |
| `umbral-architecture.png` | 2400×1800 raster of the SVG, used in the root README. |

The SVG and PNG are regenerated from the scene; after editing the `.excalidraw` file, export a new
PNG/SVG from Excalidraw itself (menu → Export image) and replace both files.

The embedded Virgil font is © Excalidraw, licensed under the SIL Open Font License 1.1.
